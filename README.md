# Unicode Large Character Viewer

Unicode 文字を大きく表示・比較するためのデスクトップツールです。  
旧字体・異体字の確認、フォントごとの字形比較、絵文字・難漢字の一覧閲覧などに活用できます。

## アプリケーション概要

本ソフトウェアは、標準のOSやGUIツールでは難しい高度な文字情報（ユニコード・コードポイント、Unicode名、UTF-8エンコーディングなど）を参照し、非常に高品質かつ正確に画面描画を目的としたユーティリティアプリケーションです。単なるフォントビューアではなく、特定の言語圏における特殊な漢字表現や最新の絵文字体系を一元管理し、開発者やデザイナー、ライターなどの「文字」を深く扱う専門家向けに設計されています。

特に、QPainterを使用した独自の描画機構（CharCanvas）により、レイアウトの影響を受けない高精細で中央寄せの文字表示が保証されるのが最大の特徴です。

QtのQPainterを用いてキャンパスの中央に配置表示しています。
資格的な描画を一般的な物とは異なり、信頼度を高めています。

高度な文字・Unicodeリファレンスおよび描画ユーティリティ
Unicodeの完全な参照を目的とし、コードポイント（U+XXXX）、正式なUnicode名、UTF-8エンコーディングを把握するための物です。
デザイナーやプログラマーなど、文字を扱う専門職にとって、互換性や正確性を検証を主目的にしています。

絵文字や難漢字などの入力は難しいが、確認などの逆引きでの用途。


## 具体例、用例

【ローカライズ検証】表現力の最適化とニュアンスの確認として、異体字などの取り扱いでトラブルを起こさない用に。
Unicodeレベルでの文字検証・参照を行う強力なローカライゼーションおよびQA（品質保証）補助ツールとして。
ゲーム翻訳やローカライズ作業において「目に見えないが致命的なエラー」（例：特定のOS/フォント環境で表示されない、誤ったコードポイントを使用する）を事前に発見し、修正することを目的としたユースケースが中心となります。

Web上では
描画の正確性と制御性（表示品質・信頼性）
高度な構造化された情報参照（リファレンス機能）
が、不完全で描画処理をブラウザ越しに参照するため不完全な描写で作業を行う必要があります。
また検索など情報の漏れなどインターネットの利用に制限がかかる環境下でも使えるようになっています。

プログラマーがユニコードの仕様を確認したい場合。
デザイナーが特定フォントでの文字描画を正確にプレビューしたい場合。
日本語や特殊な絵文字を含むテキストデータの入力を補助・確認したい場合。

印刷物、表記物などの文字がちゃんと合っているかの確認。
書いた際の正誤の確認として。

## 主な機能

### タブ構成

| タブ | 内容 |
|------|------|
| **巨大表示** | 1文字を画面いっぱいに表示。文字入力・U+コードポイント入力の両方に対応。コードポイント・Unicode名・UTF-8バイト列を表示 |
| **複数文字** | 文字列をまとめて大きく表示 |
| **異体字比較** | 2文字を並べて同一フォントで比較表示。文字・コードポイントのコピーに対応 |
| **フォント比較** | 同じ文字を2種類のフォントで並べて比較 |
| **簡易新字旧字表** | 常用漢字の新字体と旧字体・異体字を一覧表示。クリックで大きく詳細表示、検索フィルタに対応 |

### フローティングウィンドウ

- **絵文字一覧** — Unicodeの主要絵文字ブロック（顔・自然・乗り物・記号など）を一覧表示。クリックで詳細パネルに大きく表示・コピー可能
- **難漢字一覧** — CJK拡張漢字など難読・珍しい漢字を一覧表示。クリックで詳細表示・コピー可能

### その他

- **ダーク／ライトモード** 切り替え
- **フルスクリーン** 表示（`F11`）
- **枠なしウィンドウ** モード（`F10`）
- **お気に入りフォント** 登録（☆ボタン）でフォントリストの先頭に固定
- 文字・コードポイントの**クリップボードへのコピー**
- 文字パネルからの**ドラッグ＆ドロップ**によるテキスト転送

## 動作環境

- Python 3.10 以上
- PySide6（Qt6）

Windows・macOS・Linux で動作します。

Python スクリプトから実行。もしくはwindows以外の環境の方は独自でビルドして下さい。

---

## インストールと起動

### Python スクリプトから実行する場合

```bash
pip install PySide6
python unicode_viewer.py
```

### Windows 実行ファイル（.exe）を使う場合

`unicode_viewer.exe` をダウンロードしてそのまま実行してください。Python のインストールは不要です。
